# 9W4D Forbidden Scope

- First-run setup, model-selection UX, persistent profile mutation, or hot reload.
- Provider discovery, dynamic packages, marketplaces, fallback, failover, retries, or streaming.
- OpenAI hosted tools, remote response retrieval, previous-response chaining,
  conversations, stored/background responses, prompt templates, service tiers,
  provider options, reasoning continuation, or server-managed state.
- Ambient OpenAI/OpenCode credentials, organization/project headers, caller
  headers, cookies, URL credentials, query authentication, or shared role secrets.
- Changes under `agentcore/upstream` or any `FROZEN.lock` path.
- Vertex AI, external MCP/research, proposal, governance, or mutation authority.
- Changes to `resume_supported=false`, `provider_tool_loop_enabled=false`, or
  `external_read_execution_enabled=false`.
